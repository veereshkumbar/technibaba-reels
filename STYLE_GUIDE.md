# TechniBaba style guide

## Characters
- **Techni Baba** (host, from the brand logo): top-knot bun, long navy hair `#12104a`, full beard, white face, red laptop third eye `#d9534f` with dashed circuit lines, mint kurta `#5de0b0` + white stole. Narrates and reacts; never plays a real person.
- **Bit**: floating robot sidekick, mint LED eyes (blink, hearts), projects charts/data.
- **Chotu**: waiter with moustache + red cap; comic side roles (shopkeeper, uncle, customer).

## Style → when
| Style | Use for |
|---|---|
| Dark Keynote | breaking news, launches, hooks |
| Halftone Dossier | "who is", case files, allegations |
| Transit Map | timelines (stations = dates) |
| Blueprint | how it works, claimed plans |
| Swiss scoreboard | comparisons, X vs Y |
| Phone / screencast | emails, apps, notifications |
| Stock terminal | markets, numbers |
| Whiteboard | verdicts, lessons, recap |
| Pixel RPG | gaming, "game over" moments |
| Paper pop-up | stories, nostalgia |
| Glow Sketch | mystery, scandal reveals |
| Chalkboard | explainers |
| Comic | funny takes, reactions |
| Flat vector | everyday scenes with characters |
| Minimal line | quick stickman gags |

## Pacing and hooks
- Frame 0 = thumbnail + hook. New visual beat every 1–2 s. 35–45 s.
- Captions: 2–4 words per chunk, keywords highlighted lime `#C6F135`.
- End: comment question + follow CTA. Never "like if / share if" bait.

## Audio
- Voice: Piper hi_IN pratham, length 0.84, atempo 1.18, -14 LUFS master.
- Music: royalty-free track from `music/` at gain ~0.25 (ducked under voice), else built-in beat. Never ripped or trending copyrighted tracks.

## Legal guardrails
- Allegations attributed + labelled; include denials. No real photos, footage, logos. No lookalike drawings of real people.
