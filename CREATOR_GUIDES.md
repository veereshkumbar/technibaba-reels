# Creator Guides pillar (daily, evening slot)

Short tutorials that show people how to make videos like ours and what new free tools exist. Goal: comments ("send me the guide"), saves and shares.

## The promise of every guide reel
One thing the viewer can do today, for free, shown in 3–4 steps, with a comment keyword. Veer sends the written guide to everyone who comments the keyword, so every run must also deliver that guide text.

## Format
- Split layout (`SPLIT_FORMAT.md`, start from `examples/split_wifi2`) is the default: the panel shows the tool, the screen or the steps. Steps format (`STEPS_FORMAT.md`) is the alternative for pure settings walk-throughs.
- 25–35 s. Hook = the result first ("Ye reel kisi editor ne nahi banayi"), then the steps.
- Chotu asks what a beginner would ask; Baba answers in one line each.
- End: recap + "Comment karo <KEYWORD>, guide bhejunga" + "dost ko bhejo jo reels banata hai".
- Comment keyword is always GUIDE (see GUIDES.md); the guide goes on technibaba.com/guides.

## Honesty rules (do not break)
- Only describe what we really do or what a current source confirms. Our real stack: Claude writes the script and the animation code; characters are code-drawn SVG rigs; frames come from a headless browser (Playwright) into ffmpeg; voices are Kokoro (free, offline) and Veer's own cloned voice (Voicebox, on his Mac); music is a synthesised lo-fi bed; posting is through Windsor.ai after Veer approves.
- For any repo, skill or tool: open its page during the run and verify the name, what it does, the licence, whether it is free, and that it is still maintained. Show the exact repo name in the panel. No star counts unless read today.
- No "earn money fast", no follower promises, no claims about results we have not measured.
- No real logos or screenshots: redraw the UI in our own style and write the tool name as text.
- Voice cloning guides must say: clone only your own voice.
- Never show keys, tokens, account names or private repos.
